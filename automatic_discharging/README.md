# Square Coloring Stage — Source Code Reference

This code is based on the implementation accompanying the paper:

**“Square coloring planar graphs with automatic discharging.”**

The authors explicitly state in the paper that the source code is available at the following GitLab repository:
- https://gitlab.com/lucas.de_meyer/square-coloring-stage


## Reference

Nicolas Bousquet, Quentin Deschamps, Lucas de Meyer, Théo Pierron,  
*Square coloring planar graphs with automatic discharging*,  
SIAM Journal on Discrete Mathematics, 38(1): 504–528, 2024.  
DOI: 10.1137/22M1492623  
arXiv: https://arxiv.org/abs/2204.05791


## Note

This repository is intended for reimplementation and further development based on the original code and paper.
